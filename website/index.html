Multi-step agent playbooks for Paseo

One Paseo agent, the Playbook Manager, runs a playbook. Each step runs as one of its subagents in the same worktree, and the run stops at human gates that you approve in Paseo.

Playbooks are YAML files in your repository. Steps declare what they needs, so steps that are ready together run in parallel. Loops are explicit goto steps back with a limit. Inputs and outputs are typed and matched by name.

The plugin owns the rules: it validates playbooks, refuses any step or transition a playbook does not allow, keeps run state on the daemon so runs survive a restart, and wakes the manager when a step finishes. The manager makes the judgment calls: it briefs each step, reads its result and chooses the outcome.
